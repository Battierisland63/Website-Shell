Starter Kit

This starter kit outlines the foundational equipment, core applications, and network setup required for Atlantis Corporation. Having standard tools in place helps support agents resolve problems efficiently.

Hardware Software Networks

Recommended Hardware

  • Business laptops or desktops equipped with at least 16GB of RAM.
  • Dual 24-inch monitors and noise-canceling headsets for customer calls.
  • Technician toolkit and spare display cables for quick workstation repairs.

Essential Software

  • Windows 11 Pro or macOS for centralized user and device management.
  • Microsoft 365 or Google Workspace for business email and cloud storage.
  • Remote desktop software and a password manager for safe troubleshooting.

Office Networking

  • Business router with a built-in firewall to protect company resources.
  • Wi-Fi access point configured with an isolated network for visitors.
  • Cat6 ethernet cables for desks running real-time phone and VOIP systems.
